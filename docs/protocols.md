# Протоколы

Каждый протокол — отдельный компонент: в разделе «Компоненты» панели вы включаете только нужные, и роутер скачивает
их сам. Одновременно можно держать основной протокол и до шести дополнительных выходов — например, AmneziaWG для
всего заблокированного и WARP для отдельных сайтов.

| Протокол | Нужен свой сервер | Для чего |
|---|---|---|
| [AmneziaWG](#amneziawg) | да (или Amnezia Premium) | Основной VPN: быстрый, устойчив к блокировкам WireGuard |
| [Xray](#xray) | да | VLESS, Reality и другие — когда AmneziaWG режут |
| [Hysteria2](#hysteria2) | да | Быстрый протокол поверх QUIC |
| [WARP](#warp) | нет | Бесплатный выход Cloudflare, роутер получает его сам |
| [ByeDPI](#byedpi) | нет | Обход блокировок без сервера |
| [Zapret](#zapret) | нет | Обход блокировок без сервера прямо в ядре роутера |

## AmneziaWG { #amneziawg }

[AmneziaWG](https://github.com/amnezia-vpn/amneziawg-go) — WireGuard с маскировкой, которую не узнают системы
блокировок. Подходит конфиг из AmneziaVPN (файл `.conf` или ссылка `vpn://`), подписка, в том числе от панели
3x-ui, или ключ **Amnezia Premium** — роутер сам берёт у Amnezia конфиги отмеченных стран.

## Xray (VLESS, Reality) { #xray }

[Xray-core](https://github.com/XTLS/Xray-core): VLESS (в том числе Reality), VMess, Trojan, Shadowsocks. Серверы
добавляются ссылкой, подпиской или файлом; подписки обновляются по расписанию. «Проверить серверы» в панели
проверяет каждый настоящим соединением через него, а не пингом.

## Hysteria2 { #hysteria2 }

[Hysteria2](https://github.com/apernet/hysteria) работает поверх QUIC (UDP) и выжимает скорость из плохого канала.
Сервер добавляется ссылкой `hysteria2://` или подпиской.

## WARP { #warp }

Бесплатный WARP от Cloudflare. Роутер регистрируется сам — одной кнопкой, ключ создаётся на роутере и никуда не
уходит. WARP годится как отдельный выход или как **«дорога» к вашему серверу**: если провайдер заблокировал адрес
VPS, трафик к нему пойдёт через WARP. Если провайдер начнёт резать порт WARP, сторож подберёт другой сам.

## ByeDPI { #byedpi }

[ByeDPI](https://github.com/hufrea/byedpi) обходит блокировки без сервера: меняет то, как роутер отправляет первые
пакеты соединения, и система блокировок перестаёт узнавать сайт. Удобно для отдельных сайтов и сервисов.

## Zapret { #zapret }

[Zapret](https://github.com/bol-van/zapret) делает то же, что ByeDPI, но в ядре роутера (NFQUEUE) и умеет больше
приёмов. Проверен на [BE7000](routers/be7000.md) и на [AX3600](routers/ax3600.md) со стоковой прошивкой 1.1.21 (там
компонент приносит пакет поддержки ядра). На других моделях и прошивках Zapret требует отдельной проверки.

!!! tip "Что выбрать"
    Есть свой сервер — начните с **AmneziaWG**. Режут и его — добавьте **Xray (VLESS, Reality)** как запасной.
    Сервера нет — попробуйте **WARP** и **ByeDPI**/**Zapret**: часть сайтов откроется и так.
