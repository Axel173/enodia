# AmneziaWG, Xray and Zapret on Xiaomi AX3600

The **Xiaomi AIoT Router AX3600** is a Wi-Fi 6 model, and Enodia works on it with stock firmware, without OpenWrt.
The setup wizard opens SSH by itself and installs the web panel.

## What works on the AX3600

- **AmneziaWG**, **Xray (VLESS, Reality)**, **Hysteria2** — through your own server, a subscription or an Amnezia
  Premium key.
- **WARP** and **ByeDPI** — without a server of your own.
- **Zapret** — on stock firmware **1.1.21**: the AX3600 stock kernel lacks the mechanism Zapret needs (NFQUEUE), and
  the Zapret component brings a kernel support package built exactly for this firmware. Before loading the modules the
  router checks its kernel and libraries against the package; on other firmware the modules are not loaded, and the
  panel says so plainly.
- Split routing, a watchdog with backup servers, encrypted DNS, access schedules, home access.

## About this model

- **ARM64 architecture, kernel 4.4** — older than on the Wi-Fi 7 models; Enodia takes care of that itself.
- **The root password resets on every reboot** — that is how the AX3600 stock firmware works. If SSH stops taking your
  password after a reboot, it is the firmware, not Enodia: the panel and the VPN keep working.
- **About 20 MB of flash for programs, no USB port.** A program update that does not fit beside the old copy takes its
  place: the new build is first downloaded into memory, and the program stops for the swap (seconds) and starts again.

## How to install

Download the wizard from the [Releases](https://github.com/Axel173/enodia/releases) page, run it on a computer on the
router's network and follow the steps. Details — [Installation](../install.md).
