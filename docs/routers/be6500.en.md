# VPN and AmneziaWG on Xiaomi BE6500

The **Xiaomi Router BE6500** works with Enodia on stock firmware: the setup wizard opens SSH by itself and installs
the web panel, everything else is set up in the browser. Blocked sites go through the VPN, the rest goes direct.

## What works on the BE6500

- **AmneziaWG**, **Xray (VLESS, Reality)**, **Hysteria2** — through your server, a subscription or an Amnezia Premium
  key.
- **WARP** — without a server of your own, the router gets it by itself.
- **ByeDPI** — bypassing blocks without a server.
- Split routing, a watchdog with backup servers, encrypted DNS, access schedules, home access.

## The main thing about this model — flash space

The BE6500 has about 20 MB of flash for programs, and the stock firmware keeps a **backup copy of its settings —
almost 4 MB** — on it. Because of it Xray and AmneziaWG do not fit together. The setup wizard and the panel offer to
turn that copy off and name how much space it frees first. The choice survives a reboot, and removing Enodia brings the
copy back.

The BE6500 has no USB port, so protocols cannot live on a stick here — install only the ones you use.

A program update that does not fit beside the old copy takes its place: the new build is first downloaded into memory,
and the program stops for the swap (seconds) and starts again.

The BE6500 has 393 MB of memory, and the firmware itself (the Wi-Fi 7 drivers) holds almost half of it. So when memory is short,
Xray server checks run one at a time, and the router will not switch on an extra exit on Xray or Hysteria2 when memory is short
— it says why.

## How to install

Download the wizard from the [Releases](https://github.com/Axel173/enodia/releases) page, run it on a computer on the
router's network and follow the steps. Details — [Installation](../install.md).

**Architecture** — ARMv7; the wizard detects it by itself.
