# Роутеры

Enodia работает **на стоковой прошивке** Xiaomi — перешивать роутер на OpenWrt не нужно. Доступ по SSH мастер
установки открывает сам. Проект запускался и работал на этих моделях:

| Модель | Архитектура | Что важно знать |
|---|---|---|
| [Xiaomi BE3600](be3600.md) | ARMv7 | Скромный запас памяти — включайте только нужные протоколы. Zapret на этой модели ещё не проверен. |
| [Xiaomi BE6500](be6500.md) | ARMv7 | Флеш около 20 МБ, прошивка держит копию настроек почти на 4 МБ — мастер предложит её выключить. USB нет. |
| [Xiaomi BE7000](be7000.md) | ARM64 | Основная модель проекта: на ней проверяется каждая версия. USB-флешка — для протоколов или всей системы. |
| [Xiaomi BE10000 / BE10000 PRO](be10000.md) | ARM64 | Флеш поделён на несколько разделов — панель считает место по тому, где лежат файлы Enodia. |
| [Xiaomi AX3600](ax3600.md) | ARM64 | Старое ядро 4.4. Zapret — для прошивки 1.1.21 с пакетом поддержки ядра. |

Архитектуру мастер определяет сам и ставит программы протоколов, собранные под неё.

## Моей модели нет в списке

Если у вас другой роутер Xiaomi со стоковой прошивкой на OpenWrt-основе и доступ по SSH на нём открывается, Enodia,
скорее всего, встанет и на него — но такая модель не проверялась. Напишите в
[Telegram](https://t.me/+tfMLMVKG03FhMGYy): по снимку «Диагностики» из мастера можно понять, чего не хватает.
